## 大会背景

大会聚焦人工智能与工程科学交叉融合，讨论大模型、物理人工智能、数字孪生、具身智能等技术对工程科研范式和产业发展的推动作用。

AI FOR ENGINEERING 人工智能工程应用大会自 2024 年创办以来已举办两届，先后在宁波和哈尔滨举行。第三届大会将围绕新型工业化、高端装备、具身智能、智能制造、新能源、新材料、集成电路、量子等重点领域，交流人工智能与工程科学融合的新理论、新技术和新模式。

本届大会与京津冀国家技术创新中心前沿技术大讲堂联办，旨在促进前沿科技与工程应用对接，推动跨学科交流与创新合作。

## 专题方向

1. AI 大模型
2. 具身智能
3. 智能制造、建造与运维
4. AI + 新能源新材料
5. AI + 基础学科
6. 力学与航空航天航海
7. 集成电路
8. 生物信息与医工交叉
